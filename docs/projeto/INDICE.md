# ÍNDICE DA DOCUMENTAÇÃO CANÔNICA

Atualizado em: 2026-08-11

Use estes arquivos como documentação oficial do projeto:

1. `PLANO_MESTRE.md` - objetivo final, estratégia e regras permanentes.
2. `ESTADO_ATUAL.md` - situação real do projeto neste momento.
3. `ROADMAP.md` - fases e sequência de execução.
4. `PLANO_FINALIZACAO.md` - gates passo a passo até produção.
5. `BACKLOG_FINALIZACAO.md` - prioridades P0/P1/P2 e próximos itens.
6. `ARQUITETURA.md` - arquitetura atual e regras de integração/recuperação.
7. `DECISOES.md` - decisões técnicas e metodológicas vigentes.
8. `CHANGELOG_METODOLOGIA.md` - histórico de mudanças da metodologia.

## Regra de manutenção
- Atualizar `ESTADO_ATUAL.md` e `ROADMAP.md` após cada checkpoint funcional.
- Atualizar `DECISOES.md` quando houver decisão estrutural.
- Atualizar `CHANGELOG_METODOLOGIA.md` quando o método de trabalho mudar.
- Não criar novos documentos de planejamento se a informação puder ser incorporada a estes arquivos.
